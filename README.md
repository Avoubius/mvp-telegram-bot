# MVP Telegram Bot 🤖

This is a demo Telegram bot built with **Aiogram 3**.  
⚠️ Note: This bot is for **portfolio/demo purposes only**.  
It does not handle real payments or bookings.

---

## ✨ Features
- 📅 Demo booking system (choose court, add subscription)
- 🛒 Simple catalog with demo items
- 🔑 Environment-based configuration (`.env`)
- 🧩 Modular structure with handlers and keyboards
